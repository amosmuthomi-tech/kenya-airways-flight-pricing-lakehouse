# Raw data

The 24 MB source file is not committed. It is the public "Flight Price Prediction" dataset
(300,153 rows of Indian domestic flight fare quotes, 12 columns).

To reproduce: download it, save it here as `airlines_flights_data_20260908.csv`
(the date suffix is the snapshot date the pipeline derives from the filename; see
`documentation/assumptions.md`), then follow `documentation/reproduction_steps.md`.
